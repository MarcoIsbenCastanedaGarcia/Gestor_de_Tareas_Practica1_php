“Hacer un sistema web que tenga incluido un sitio web, con la función de sistema de gestión de tareas con mínimo 4 páginas a contenido o temática libre para cada una. Debe tener un inicio de sesión, apartado de registro y una interfaz principal donde la persona pueda hacer un CRUD de tareas. Así mismo, debe tener un calendario donde puedan visualizarse las tareas”.

Para la parte de sistema web y sitio web toma en cuenta la imagen o imaganes anexadas, La parte del sistema web va a incluir como introducción una pagina principal que lleva a un inicio de sesion el cual va a tener un apartado de usuario (que va a ser el nbombre_apellido del usuario que vamos a crear) y una contraseña, ambos ya preestablecidos, si alguno de los datos está mal o directamente no existe tiene que enviar una alerta de que alguno de los datos está mal, en el caso de que los datos concuerden, tiene que entrar a una parte de gestor de tareas, donde se van a poder hacer registros dentro de una base de datos que vamos a especificar igual en una imgane o imagenes anexadas, a partir de el apartado anterior se va a poder axeder a un apartado de calendario el cual va a registrar las fechas de las tareas registradas
en la parte de registros de tareas agregar un lector de txt que pueda hacer registros en la tabla especificada, asi mismo que los registros especificados por el usuario se puedan descargar con un txt formato json,
despues tenemos una parte de sitio web la cual igualmente va a tener como paginal centrar la pagina inical que especificamos al inicio, esta a parte de tener el apartado de inicio de sesion explicado anteriormente va a tener otros apartados como contacto, preguntas frdcuentes y acerca de, las caracteristicas de estos estarán especificadas en las imagenes anexadas. 
tambien seran anexadas imagenes queseran una representación de la forma en la que queremos que esten las carpetas, que será una captura en visual studio code de un proyecto alterno que usamos como ejemplo, sigue la estructura de las carpetas y de los archivos para crear este poryecto.
la forma de reaalizar la base de datos va a estar especificada en un mapa de entidad rlación que será anexado, necesito que crees un script para crear la base de datos junto a sus tablas y sus atributos en base al diagramaa entidad relacion. toma en cuenta que usaremos maria db.
